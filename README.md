# Консультация / Maslahat

Двуязычный учебный сайт-тренажёр. Автор: ученик 11а класса Русинов Давид.

## Запуск

Откройте `index.html` двойным щелчком. Установка программ и сборка не требуются.

Вкладки открывают отдельные экраны без прокрутки к секциям. Доступны 40 ситуаций в четырёх направлениях (по 10 в каждом), объяснения ответов, повторные попытки и история результатов. Весь интерфейс и задания переведены на русский и узбекский языки. История и язык сохраняются в localStorage текущего браузера. Если браузер запрещает сохранение, тренажёр работает в течение текущего открытия страницы.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое этой папки**, включая `assets`, в корень репозитория. Главный файл `index.html` должен лежать в корне.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
5. После завершения публикации GitHub покажет адрес сайта.

Относительные пути подходят для GitHub Pages, в том числе для адресов вида username.github.io/repository/.

## Файлы

- `index.html` — точка входа.
- `styles.css` — адаптивное оформление.
- `app.js` — интерфейс, переводы, сценарии, сохранение результатов.
- `assets/` — локальные фотографии и SVG-иконка.
- `CREDITS.md` — источники изображений.

Google Fonts загружает Manrope при наличии интернета. Без сети используется системный шрифт. Фотографии хранятся локально. Сайт не использует API, ключи, аккаунты или сервер.

Учебные сценарии медицинского раздела посвящены общению и не заменяют медицинскую консультацию.

## Сложность и сертификат

Перед тренировкой выбирается уровень: лёгкий (2 варианта), средний (3 варианта), сложный (4 варианта, объяснения только в итоговом разборе). В каждом уровне доступны все 10 вопросов направления. Порядок вариантов перемешивается. Один правильный ответ = 1 балл.

В разделе «Мой прогресс» сертификат открывается после завершения всех четырёх направлений на одном выбранном уровне. Прохождение засчитывается независимо от балла. Учитываются последние полные попытки каждого направления на этом уровне: максимум 40 баллов. Можно повторить направление для обновления результата.

Участник вводит имя, фамилию и класс. Сертификат скачивается в PNG (1800 × 1273): содержит результаты по направлениям, общий балл, процент, сложность, название и адрес сайта, автора Русинова Давида и дату/время с часовым поясом браузера в момент выдачи. Используются часы устройства участника. Форма не передаёт данные на сервер.

Сертификат — учебный документ участия. Серверной проверки подлинности нет. Старые тренировки из 3 вопросов остаются в истории, но не открывают сертификат.

Дополнительные файлы `questions.js` и `features.js` обязательны для загрузки на GitHub вместе с обновлёнными `app.js`, `index.html`, `styles.css`. Папка assets остаётся прежней.
