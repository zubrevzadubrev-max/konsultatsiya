# Консультация / Maslahat

Двуязычный учебный сайт-тренажёр. Автор: ученик 11а класса Русинов Давид.

## Запуск

Откройте `index.html` двойным щелчком. Установка программ и сборка не требуются.

Вкладки открывают отдельные экраны без прокрутки к секциям. Доступны 12 ситуаций в четырёх направлениях, объяснения ответов, повторные попытки и история результатов. Весь интерфейс и задания переведены на русский и узбекский языки. История и язык сохраняются в localStorage текущего браузера. Если браузер запрещает сохранение, тренажёр работает в течение текущего открытия страницы.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите **содержимое этой папки**, включая `assets`, в корень репозитория. Главный файл `index.html` должен лежать в корне.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
5. После завершения публикации GitHub покажет адрес сайта.

Относительные пути подходят для GitHub Pages, в том числе для адресов вида username.github.io/repository/.

## Файлы

- `index.html` — точка входа.
- `styles.css` — адаптивное оформление.
- `app.js` — интерфейс, переводы, сценарии, сохранение результатов.
- `assets/` — локальные фотографии и SVG-иконка.
- `CREDITS.md` — источники изображений.

Google Fonts загружает Manrope при наличии интернета. Без сети используется системный шрифт. Фотографии хранятся локально. Сайт не использует API, ключи, аккаунты или сервер.

Учебные сценарии медицинского раздела посвящены общению и не заменяют медицинскую консультацию.
